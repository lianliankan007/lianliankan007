## 维护方式

- **给自有或 Fork 仓库加标签**：仓库首页 → About 齿轮 → Topics。
- **给收藏加分类**：项目的 Starred 下拉菜单 → 选择或新建列表。支持多选，分类只影响自己的收藏。
- **查询自己的标签**：在 GitHub 搜索框输入下方语法；将 `java` 替换为目标 Topic。
- **查询收藏**：打开对应分类列表，或在 Stars 页按仓库名 / 上游 Topic 搜索。收藏列表与仓库 Topics 分别维护。

```text
user:lianliankan007 fork:true topic:java
```

只查 Fork，将 `fork:true` 改为 `fork:only`；只查自建私人项目，移除 `fork:true` 并加上 `is:private`。

> Topics 名称本身公开，请使用通用技术词。描述不足的项目暂标记 uncategorized，可在补充简介后调整。

项目表按 2026-10-14 的清单整理；分类和标签入口会查询 GitHub 的最新结果。
